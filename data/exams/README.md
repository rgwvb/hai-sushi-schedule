# 歷屆警察特考題庫

資料來源：[考選部考畢試題查詢平臺](https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx)。包含平臺提供的民國 82–115 年警察特考、一般警察特考各類科，以及早期空中警察技術人員考試；合併舉行的鐵路、關務、國安與移民考試不納入。

完整官方試題、標準答案及更正答案的連結保留在每份試卷資料中。自動練習僅使用能完整辨識題號、四個文字選項與官方答案的題目；更正答案優先於原標準答案，並支援「A 或 C 均給分」。掃描卷、申論、圖表、依賴外部前文以及無法可靠辨識的題目，以完整原卷查閱。歷屆答案依當年度公布結果，不代表現行法規；本題庫沒有宣稱提供官方詳解。

## 檔案與載入

`manifest.json` 僅包含年份與統計。每年有一個 `.catalog.json` 試卷目錄和一個 `.json` 題庫。選年份時只載入目錄，開始作答才載入題庫；全年度混合每輪取最多三個年份、二十題。相同年度的共用試卷資料去除重複題庫，原卷目錄仍保留各類科的來源。

每個題目資料列為 `[原題號, 題幹, 四個選項, 可接受的選項索引, 原卷頁次, 官方更正說明]`。

## 更新與驗證

```sh
python -m pip install requests beautifulsoup4 pymupdf
python scripts/build_exam_archive.py --bundles --workers 3
python scripts/validate_exam_archive.py
node scripts/exam_archive_test.mjs
```

下載使用考選部的「試題打包」功能，每批不超過官方限制的八科。HTML 目錄、原始 PDF 與 ZIP 暫存在 `.exam-cache/`，不納入網站部署；已公開的題庫為靜態檔案。更新過程不需要改變網站讀者的權限。
