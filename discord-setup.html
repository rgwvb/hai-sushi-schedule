DISCORD · 指令與按鈕版

輸入 /開始，展開警察生涯。

在文字頻道接案，按 A／B／C 選擇處置，再查看分析、績效與升遷進度。每位玩家各自存檔，大家可以觀看彼此的遊玩結果。

機器人程式已提供；仍需在你的電腦或主機啟動，才會在 DC 上線。網頁版與 DC 版存檔分開，不會自動同步。

01 · 下載並啟動

先用 Windows 電腦開啟機器人

  1. 安裝 Node.js 24 LTS（24.17.0 以上）。
  2. 下載專案 ZIP，先全部解壓縮。
  3. 打開 discord-bot 資料夾，雙擊 start-windows.bat。
  4. 第一次會開啟設定檔，在記事本填好下一步的三個值，儲存並關閉記事本。
下載專案 ZIP 安裝 Node.js
02 · 設定同一個應用

在自己的電腦填入三項設定

設定檔欄位去哪裡找
DISCORD_TOKEN開發者後台 → Bot → Reset Token／Copy
DISCORD_APPLICATION_ID同一應用 → General Information → Application ID
DISCORD_GUILD_IDDC 開啟開發者模式，右鍵伺服器圖示 → 複製伺服器 ID

Token 是密碼，只填在自己電腦的 .env，請勿貼進聊天室或提交 GitHub。

可以沿用已邀請到伺服器的應用。此版本不需要 Activities 或 URL Mappings。General Information 的 Interactions Endpoint URL 留空，不需開啟特權 Intent。

開啟 Discord 開發者後台
03 · 在文字頻道玩

看到「機器人已上線」，輸入 /開始

建立姓名與任職單位，從 2010 年、22 歲的正式任職警員開始。

指令玩法
/任務依職務接案，按 A／B／C 作答，查看分析與績效。
/角色查看階級、年資、績效與年度考績。
/履歷回顧勤務、任命及研習紀錄。
/訓練連續答對三題，完成當前需要的模擬研習。
/升遷檢查條件，符合後按鈕確認申請。
/說明查看規則與指令。

每件正式勤務推進一個遊戲月份，每 12 件結算考績；每次升遷還需現職年資、績效、最近兩年考績及指定研習，不能連按跳級。

關閉啟動視窗、休眠或關機，機器人就會離線。下次重新開啟會繼續存檔；全天運行需部署到持續執行的主機。

四個頻道，一起看大家的生涯

頻道用途
警察角色每位玩家固定一張資料卡，顯示角色、階級、職位、單位、年資與績效，進度變動時自動更新。
警察遊戲公開接案與作答，只有本人能操作自己的案件。
警察排名依職位、績效、完成勤務數排列前 20 名，條件相同並列，榜單自動更新。
警察說明新手玩法、九個職位職責、升遷條件、績效考績與研習常見問題。

機器人有「管理頻道」權限時會自動建立。若沒有，可授權後由管理員輸入 /遊戲頻道 重試，或使用該指令指定既有文字頻道，說明頻道可單獨指定。一般遊玩在「警察遊戲」進行，也可用 /排名 查看榜單。角色與榜單重啟後沿用原訊息。

找不到指令或機器人沒回應？

  1. 確認啟動視窗顯示註冊成功，且機器人已上線。
  2. 確認設定的是同一個應用與你正在使用的伺服器。
  3. 邀請需包含 bot 與 applications.commands。私人應用 Install Link 保持 None／無，再到 OAuth2 → URL Generator 產生 Guild Install 邀請，由擁有者帳號安裝。
  4. 頻道允許機器人檢視頻道、傳送訊息、嵌入連結；玩家可使用應用程式指令，不需授予管理員。

DC 首版採簡化遊戲規則，使用網站既有 60 個情境題；尚未包含網頁版全部考試、輪調與歷屆試題。研習是情境練習，不是官方訓練試題。程式與模擬互動已測試，仍需在你的 Discord 應用完成實機驗收。
