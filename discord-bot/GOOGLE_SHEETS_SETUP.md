# Discord 玩家試算表

「DC玩家總表」是 Firebase 的顯示副本。它只匯出指定伺服器的角色姓名、官階、職務、配階、單位、遊戲年月、年資、績效、考績及 Discord ID，不包含憑證或其他伺服器資料。修改試算表不會回寫遊戲。

以既有服務帳戶的專用金鑰授權 Sheets API；只分享目標試算表的編輯權限給該帳戶。啟用 Google Sheets API，將試算表 ID 存入 Railway 的 `GOOGLE_SHEETS_ID`。既有 `FIREBASE_SERVICE_ACCOUNT_JSON` 保持私密，不寫入版本控制。試算表需保留名稱為 `DC玩家總表` 的專用工作表。

啟動後同步一次；玩家操作後約 5 秒更新，另每 60 秒同步。同步只替換該分頁 A:P 的資料區域，保留其他分頁。資料列使用明確的字串／數字型別，Discord ID 保留完整字串，玩家名稱不當成公式。同步失敗不影響 Firebase 結算與 Discord 遊玩，後續會重試。

正式記錄 `GOOGLE_SHEETS_SYNC_READY rows=...` 才代表該次寫入完成；失敗記錄只含錯誤碼，不列印請求憑證。

## 機關資料庫

「機關資料庫」A5:I27 為全台 22 縣市警察局名錄，以警政署官方名錄核對。服務啟動及每 60 秒唯讀載入 A5:I100；新的輪調職缺依啟用名單列出所有符合職務序列與機關層級的外縣市，不是即時人事缺額。F 欄可選啟用／停用，僅控制跨縣市選填。機關 ID、縣市與機關類型保留原值，22 列不可重複或缺漏。

欄名、列數、ID、縣市、機關類型與名稱驗證通過後才整批替換記憶體名錄；失敗沿用上次有效名錄，冷啟動備援為版控的完整 22 縣市。玩家總表同步不會覆蓋機關資料庫。`AGENCY_CATALOG_SYNC_READY rows=22 enabled=...` 表示讀取成功；不會將修改過的玩家總表回寫 Firebase。
