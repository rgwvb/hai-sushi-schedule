# Discord 共用網頁版遊戲

新玩家輸入 `/開始`，以 Discord 按鈕、選單、輸入視窗操作網頁版的角色建立、入警路線、備考、考試、受訓、分發、職務勤務、指揮、學堂、歷屆題庫、人力演練、考績與升遷輪調。考生沒有階級，指揮介面依網頁的主管資格開放。

舊玩家在 `/角色` 選擇「切換網頁規則（保留進度）」。轉換保留角色姓名、職位、個人官階、任職年月、完成勤務、累計成果及考績，並將完整原始角色保存在 `webLegacyBackup`。A/B/C 對應為甲/乙/丙。簡化版研習不會自動換成網頁版正式的官等訓練資格。後續按網頁版規則結算，退休條件也隨現職判斷。

## 實作與更新

- `web-engine.json` 由根目錄 `index.html`、`scripts/exam_archive.js`、`scripts/workforce_scenarios.js` 產生。只加入狀態保存與操作轉接 hook，不重寫資格、計分或升遷公式。
- 修改網頁後執行 `node discord-bot/sync-web.mjs`，連同輸出一起提交。`--check` 與測試會拒絕不同步的版本。
- `web-game.mjs` 每次操作使用獨立、執行後關閉的 JSDOM，沒有帳號登入或 Firebase 網頁 SDK，也不執行遠端 JS。
- 官方歷屆 JSON 與全國單位目錄由既有 GitHub Pages 網址按需讀取；只允許固定來源的 JSON 路徑，快取不含玩家資料。題庫延遲時沿用網頁備援題。
- 職務題、選項、主題測驗、原卷測驗與人力配置的進度會序列化到角色存檔，重啟可續答。大型原卷目錄不存入每位玩家文件，恢復時重新讀取靜態目錄。
- 選單只能執行上一張畫面已發出的動作。所有按鈕綁定本人與版本，過期操作不得重複結算；Firestore 的讀寫仍在同一個交易中。
- 公開角色卡、排名、Google 試算表讀取同一份新進度。DC 與網頁版的存檔目前分開，不包含帳號綁定或跨平台共用存檔。

## Discord 的操作差異

Discord 使用卡片和分頁，無法複製瀏覽器版面、滑桿與側欄。解析後按「下一題」或「開始／換一題」繼續，避免背景定時器改動已顯示的操作卡。所有遊戲計分、資格判斷與動作仍交給共用引擎。

勤務與測驗使用精簡的一題一卡，直接按 A／B／C／D，解析後按下一題；長題幹可翻頁，不截掉題目。上方固定勤務、角色、輪調、升遷與更多按鈕。僅顯示一張配階縮圖，不再重複張貼標題、勤務數據及注意事項。輪調每頁四筆，保留原本的選填／確認規則。
